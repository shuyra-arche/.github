# Agent entry point

This repository owns the shared engineering standards for `shuyra-arche`.

At the start of each new session, before substantive analysis or edits:

1. Read the local `README.md`, `CONTRIBUTING.md` and
   `docs/engineering/README.md`.
2. Read `docs/engineering/agent.md`, `docs/engineering/code-organization.md`
   and `docs/engineering/testing.md` in this checkout. Read the other
   indexed standards when relevant to the task; changes and publication
   require `branch.md` and `pull-request.md`.
3. Check for applicable nested agent instructions before changing a subtree.

Use this checkout as the source for standards while editing this repository;
do not replace local changes with rules fetched from remote `main`. Read the
actual contents of referenced files, not just their links or prior summaries.

Keep general rules in the engineering documents and this entry point short.
This is a documentation repository: review the final diff, check Markdown
links and template consistency, and report verification accurately. Builds
and runtime tests are not applicable to prose-only changes.
