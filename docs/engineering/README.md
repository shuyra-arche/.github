# Shuyra engineering standards

These documents define the shared engineering conventions for `shuyra-arche`.
Repository guidance can link here and describe local requirements or exceptions.

| Standard | Scope |
| --- | --- |
| [Repository](repository.md) | Ownership boundaries, naming, documentation and lifecycle |
| [Code organization](code-organization.md) | Recursive semantic locality across modules, files, types and functions |
| [Branch](branch.md) | Branch names, protection and cleanup |
| [Pull request](pull-request.md) | Titles, review, verification and merge |
| [Release](release.md) | Release tags, channels and publication |
| [Dependency](dependency.md) | Dependency direction, compatibility and reproducibility |
| [Testing](testing.md) | Proposed repository, Cluster and system validation boundaries |
