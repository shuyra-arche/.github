# 圜

*一种关于一致性的设计。*

[阅读英文版](README.md)

## 宣言

我们无法穷尽真实，因此不宣称拥有最终的答案。

我们通过构造理解，通过检验发现理解的边界，并在认识到局限时重新修正。

我们以边界建立安全，以组合创造秩序，以质疑保留改变的可能。

我们珍视已经成立的成果，却不将它们视为不可改变的结论。

**我们不要求秩序永恒。我们要求创造秩序的自由。**

## 直白地说

### 我们通过构造理解

我们不需要等到理解一切，才开始创造。构造一个能够运行的东西，可以让想法接受现实的检验。成功让我们有所发现，失败同样如此。

创造不只是理解的结果，也是理解不断形成的过程。

### 我们有目的地质疑

我们可能犯错，包括那些曾经认真辩护、投入许多时间的想法。但质疑不等于必须改变一切。

一次修正应当带来更清晰的理解、更可靠的行为，或者新的可能。保留经过检验的设计，与替换它一样，都应当是经过思考的选择。

### 边界让自由成为可能

明确的边界，使独立的部分能够协作，而不必放弃各自的责任。当它们能够被安全地连接与组合，人们就可以创造事先没有被规定的组织形式。

约束并不必然与自由相对。恰当的约束，可以让自由真正得以实现。

### 一致性不等于永恒

我们希望一个结构的责任、假设与局限能够被共同理解。当证据改变，我们愿意修改结构；当一个设计已经赢得信任，我们也愿意保留它。

### 我们对创造负责

我们区分证据与愿望，坦诚面对未知，并承担创造所带来的责任。包括这份宣言在内，所有原则都可以被重新审视。

**我们创造，我们理解，我们修正。然后继续创造。**
