# 圜

*一种关于一致性的设计。*

[英文版](README.md)

我们喜欢把想法做出来。

很多时候，起初觉得已经想明白了，真正动手后才发现还有没考虑到的地方。于是试着改一改，看看是不是更好。有时要推倒重来，也有时发现原来的办法其实挺不错。

我们不觉得自己能彻底理解世界。但不必等到一切都想清楚，才开始创造。

我们喜欢清楚的边界。它们让不同的部分可以安全地合作；也喜欢自由的组合，因为总有人会想出我们没想到的用法。

我们在意一致性，不是想找到一种永远不变的结构，而是希望能说清楚每个选择的理由。当有新的发现，就有重新选择的余地。

当然，怀疑不是为了否定一切。值得保留的东西就留下，发现错了也不用硬撑。

这些想法也许以后还会变。

**我们不要求秩序永恒。我们只想保留重新创造它的自由。**
